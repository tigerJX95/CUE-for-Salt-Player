# 椒盐播放器 CUE 分轨支持

[中文](README.md) | [English](README_EN.md)

CUE for Salt Player 是椒盐播放器桌面版插件。它读取外置 CUE 或 FLAC 内嵌 CUE，让你在专辑详情页和歌曲页按曲目浏览、搜索和点播。

**当前版本 v0.9.0 · 2026-11-28**

- **多碟共享 CUE**。一份放在专辑父目录的 CUE 可以引用 CD1、CD2 等分碟目录里的整轨。「重新识别 CUE」会同步更新共用该 CUE 的分轨。
- **分轨管理**。管理窗口随专辑的重新识别更新，保留搜索、筛选和仍存在的分轨勾选。音频缺少专辑或艺术家标签时，仍按各碟对应的 CUE 显示分轨。
- **播控条刷新**。播放期间重新识别 CUE 时直接更新分轨信息，避免短暂闪回整轨标题。
- **整轨艺术家**。歌曲艺术家缺失时尝试专辑艺术家、CUE 的专辑署名和同一音频的曲库标签。标签仍缺失时，可识别 `艺术家.-.[专辑名]` 格式中的署名。从「歌曲」页点播整轨时，播控条可直接显示列表已识别的署名，避免短暂显示「未知艺术家」。
- **上一首和下一首**。跳过已移除的分轨，多碟专辑可从相邻碟可播放的分轨继续。
- **开源链接**。可从椒盐的模组管理打开插件的 GitHub 仓库。

[历史更新](CHANGELOG.md)

> [!IMPORTANT]
> **WAV 整轨需要外置 CUE。** 可将匹配的 `.cue` 放在 WAV 同一目录，多碟专辑也可以共用专辑父目录中的 CUE。WAV 内的定位标记不会被插件识别为分轨。
>
> 内嵌 CUE 仅支持 FLAC 的 `CUESHEET` 文本标签和二进制 CUESHEET 元数据块。歌词匹配和同步请使用外部歌词方案。

## 项目由来

整张 CD 抓轨后常保存为一个音频文件，曲名和各首歌的起点则记录在 CUE 里。插件把这些分轨带进椒盐原生界面，让整轨专辑也能按单曲浏览和播放。点播时，播放器会跳到整轨中的对应位置。

## 目前功能

- **专辑详情页**。在对应光盘下显示分轨的轨号、曲名和各自时长。多碟专辑按光盘显示分轨。顶部「歌曲」按实际显示的分轨和普通歌曲计数。
- **歌曲页**。分轨独立显示，可按曲名搜索、点播、勾选和全选，条目带封面、艺术家、音质徽标和时长。
- **分轨播控**。播控条和播放界面显示当前分轨的曲名、艺术家及分轨内的进度。Windows 任务栏的进度条也按当前分轨计算。顺序模式可切换相邻分轨，整轨播完后继续当前队列；随机模式按当前队列中的独立分轨和普通歌曲选择。多碟专辑可在光盘边界衔接。
- **艺术家与桌面标题**。优先使用分轨和 CUE 专辑级的有效 `PERFORMER`，再使用整轨艺术家或曲库中的专辑艺术家。Windows 任务栏和 Ubuntu Dock 的窗口标题随播放更新。
- **封面补充**。椒盐没有原生封面时，可使用音频同目录的图片。多碟专辑的顶部封面还可使用各碟文件夹共同父目录中的图片。
- **数字化碟片联动**。同时启用 SPW Digital Disc v1.11.0 时，切换 CUE 分轨会触发出碟动画。

## 安装与使用

1. 在椒盐的模组管理中导入 `.spmod` 并启用插件。
2. 按提示授予快捷键、曲库读取以及方法与 UI Hook 权限。
3. 把整轨音频加入曲库。使用外置 CUE 时，将 `.cue` 放在音频同目录，或按下文的多碟布局放在专辑父目录。使用内嵌 CUE 时，加入含有 CUE 的 FLAC 文件即可。
4. 打开椒盐的「专辑」，在专辑详情页点播「分轨」列表中的曲目。也可以在「歌曲」页搜索曲名并直接播放。

### 播放高亮与重新识别

专辑详情页和歌曲页的强调色随分轨切换和跨碟播放更新。暂停时保留当前曲目状态。保留整轨行时，列表中已显示当前分轨的对应整轨行使用普通颜色。

修改曲名、艺术家、轨数、时间或封面后，可在专辑详情页第一张光盘标题右侧，或「管理分轨」窗口中选择「重新识别 CUE」。即使编辑器保留了 CUE 文件的大小和修改时间，手动重新识别也会强制重读。其他专辑的已有分轨条目会被复用。失去 CUE 匹配的音频会恢复显示原整轨条目。播放本专辑时，曲名、艺术家、分轨时间范围和目录封面都会重新读取。

### 随机播放与播放范围

使用椒盐的播放模式按钮选择「随机播放」。候选范围以当前原生播放队列为准：队列中每首可播放的 CUE 分轨和每首普通歌曲各作为一项，当前曲目不会被立即再次选中。分轨结束和手动下一首都会进行选择；有已播记录时，上一首可返回先前播放过的曲目。仅从歌曲页隐藏的分轨仍保留专辑播放能力，已从曲库移除的分轨不参与插件的随机候选。

分轨随机需要读取宿主队列与模式。候选在后台准备，诊断中的「播控条／队列」显示状态。候选尚未准备好或宿主入口不兼容时，由宿主负责切歌。椒盐的原生队列仍按音频文件显示。

在主「歌曲」页点播后，顺序播放与列表循环使用点播时的列表顺序，包括所选排序和当前搜索结果。普通歌曲、保留的整轨和独立分轨都占各自的位置。列表中的整轨按完整文件播放。

在「专辑详情」点播后，分轨按光盘及轨号顺序播放。到达当前碟末分轨后，如下一碟有可播放分轨则从其中第一首开始；没有可衔接的碟时按椒盐播放模式继续。

### 在分轨窗口中筛选与恢复

按 **Ctrl+Alt+U** 打开窗口。播放多碟专辑中的整轨时，窗口会查找曲库中同一专辑的其他碟，一并显示它们的分轨和恢复记录。手动打开 CUE 时，窗口显示该文件引用的分轨。搜索框支持曲名、艺术家和多个空格分隔的关键词，英文不区分大小写。「全部／已隐藏／已移除」可与搜索组合使用；同时有两种记录的分轨在两个状态筛选中都可找到。

勾选曲目前的复选框，或点击「全选结果」，再使用「恢复勾选分轨（N）」批量恢复。只有当前筛选结果中有隐藏或移除记录的勾选项会计入 N。没有勾选时显示 0 并禁用，不会自动改为恢复高亮的一首；高亮仅用于播放定位。修改搜索词或状态筛选会清除勾选，避免误操作不可见条目。

「恢复当前结果（N）」可一次恢复本窗口当前筛选结果中已隐藏或移除的分轨，不影响其他 CUE 或被筛掉的条目。「恢复本专辑」处理本专辑全部记录，不受筛选影响；「全部恢复」处理插件保存的所有专辑记录。

窗口中的播放强调色与勾选分开显示。「定位播放」清除搜索和状态筛选，并将列表滚动到正在播放的分轨。多音频内容按文件分组，编号沿用完整结果的来源顺序；这与音频标签中的光盘号不一定相同。双击已匹配曲库的分轨可点播。若它属于当前音频，按钮显示「跳到分轨起点」；若来自其他已匹配音频，按钮显示「播放分轨」。选中项被筛掉时，点播暂时不可用。

### 移除、隐藏和恢复 CUE 分轨

在「歌曲」页勾选一首或多首 CUE 分轨，再右键其中一首打开插件菜单。括号里的数字是本次操作的 CUE 分轨数。未勾选分轨时，菜单对右键点中的分轨操作，显示「（1）」。

- **从曲库移除所选分轨（N）**。分轨从歌曲列表、歌曲搜索结果和专辑详情页中移除。
- **从歌曲页隐藏所选分轨（N）**。分轨从歌曲列表和歌曲搜索结果中隐藏，仍可在专辑详情页浏览和点播。

**混选 CUE 分轨和普通歌曲时，无法用一个右键菜单移除全部条目，需要分两次操作。**

1. 先勾选要移除的 CUE 分轨，右键其中一首分轨，选择「从曲库移除所选分轨（N）」。如果只想从歌曲页隐藏这些分轨，则选择「从歌曲页隐藏所选分轨（N）」。
2. 再只勾选要移除的普通歌曲，右键其中一首，使用椒盐原生菜单的「从音乐库中移除」。普通歌曲包括单曲文件和整轨音频条目。

连续隐藏或移除多首时，记录会累加保存并同步到恢复窗口。批量操作按当前歌曲列表中的勾选分轨计算，艺术家详情的歌曲列表无需依赖主歌曲页。插件会在重启后保留分轨的移除和隐藏记录。两项操作均保留磁盘上的整轨音频和 CUE 文件。恢复时可从专辑详情页打开「管理分轨」，也可按 **Ctrl+Alt+U** 打开分轨窗口。

- **恢复勾选分轨（N）**。勾选一首或多首标为隐藏或移除的分轨，再点击按钮恢复。
- **恢复当前结果（N）**。恢复当前窗口筛选结果中的全部隐藏或移除记录。
- **恢复本专辑**。从专辑详情页打开「管理分轨」后，可一次恢复本专辑中有记录的分轨。
- **全部恢复**。恢复所有由插件隐藏或移除的分轨。

在专辑详情页或「管理分轨」中选择「重新识别 CUE」，可以重新读取该专辑的 CUE。

## CUE 和封面怎么放

把 `Album.flac`、`Album.cue` 和可选的 `cover.png` 放在同一目录。CUE 的 `FILE` 行应指向实际音频，例如 `FILE "Album.flac" WAVE`。插件优先采用能匹配音频的同名 CUE，其次查找同目录中唯一匹配的 CUE。支持 UTF-8、GBK 和带 BOM 的 UTF-16。

找不到匹配的外置 CUE 时，插件读取 FLAC 的内嵌 CUE。优先使用带曲名和艺术家信息的文本标签。二进制 CUESHEET 块提供轨号和时间，曲名按 `TRACK 01` 等格式显示。

椒盐缺少原生封面时，插件按以下顺序查找。图片无法解码时继续尝试下一项。

| 优先级 | 文件名 |
| --- | --- |
| 1 | `cover.png` |
| 2 | `cover.jpg` |
| 3 | `folder.png` |
| 4 | `folder.jpg` |

歌曲页的 WAV 整轨先查找音频同目录的封面。若音频位于 `CD1`、`CD2` 等分碟目录，同目录没有可用封面时再查找上一级的共享封面。

播放时也可使用分碟目录上一级的共享封面。椒盐原生封面优先，目录封面用于补齐播放画面。

多碟专辑可在 `Album/CD1/` 和 `Album/CD2/` 各放一份 CUE，也可把共享 CUE 放在 `Album/`，用 `FILE "CD1/Disc1.wav" WAVE` 和 `FILE "CD2/Disc2.wav" WAVE` 引用各碟音频。匹配到的同目录 CUE 优先。专辑详情页按椒盐曲库中的专辑归类展示各碟分轨。

## 设置

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 在歌曲页显示 CUE 分轨 | 开启 | 在主「歌曲」页显示和搜索分轨，并在艺术家详情的歌曲列表显示分轨 |
| 识别 CUE 后隐藏整轨 | 关闭 | 专辑详情按光盘分别隐藏有可显示分轨的整轨行。光盘只有一条整轨时，隐藏后，分轨列表紧接在光盘标题下。歌曲页隐藏与 CUE 匹配的原整轨条目 |

## 兼容性与排查

- 专辑详情的分轨按椒盐曲库的专辑归类判断。椒盐归入同一专辑的多张光盘可以分放在不同目录。
- 按 **Ctrl+Alt+U** 可查找当前 CUE，或用「打开 CUE 文件…」选择外置 CUE。独立分轨窗口可查看引用多个文件的 CUE，双击已匹配曲库的分轨可从起点播放。
- 如果专辑页没有分轨，先检查整轨是否已加入曲库并归入对应的专辑。使用外置 CUE 时再检查 `FILE` 行和文件位置。可用独立分轨窗口的「诊断」或「原生接口报告」继续排查。
- 原生界面通过 Workshop 接口接入。升级椒盐后，相关入口可能需要重新适配。
