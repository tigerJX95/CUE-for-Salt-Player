# 椒盐播放器 CUE 分轨支持

[中文](README.md) | [English](README_EN.md)

CUE for Salt Player 是椒盐播放器桌面版插件。它读取外置 CUE 或 FLAC 内嵌 CUE，让你在专辑详情页和歌曲页按曲目浏览、搜索和点播。

**当前版本 v0.2.0** · [更新日志](CHANGELOG.md)

> [!IMPORTANT]
> **WAV 整轨需要外置 CUE。** 将匹配的 `.cue` 放在 WAV 同一目录，例如 `Album.wav` 和 `Album.cue`。WAV 内的定位标记不会被插件识别为分轨。
>
> 内嵌 CUE 仅支持 FLAC 的 `CUESHEET` 文本标签和二进制 CUESHEET 元数据块。歌词匹配和同步请使用外部歌词方案。

## 项目由来

整张 CD 抓轨后常保存为一个音频文件，曲名和各首歌的起点则记录在 CUE 里。插件把这些分轨带进椒盐原生界面，让整轨专辑也能按单曲浏览和播放。点播时，播放器会跳到整轨中的对应位置。

## 目前功能

- **专辑详情页**。在对应光盘下显示分轨的轨号、曲名和各自时长。光盘标题采用椒盐原生样式。
- **歌曲页**。分轨独立显示，可按曲名搜索、点播、勾选和全选，条目带封面、艺术家、音质徽标和时长。
- **分轨播控**。播控条和播放界面显示当前分轨的曲名、艺术家及分轨内的进度。上一首和下一首可切换到相邻分轨。
- **艺术家与桌面标题**。优先使用分轨和 CUE 专辑级的有效 `PERFORMER`，再使用整轨艺术家或曲库中的专辑艺术家。Windows 任务栏和 Ubuntu Dock 的窗口标题随播放更新。
- **封面补充**。椒盐没有原生封面时，可使用音频同目录的图片。分轨共用这张封面。

## 安装与使用

1. 在椒盐的模组管理中导入 `.spmod` 并启用插件。
2. 按提示授予快捷键、曲库读取以及方法与 UI Hook 权限。
3. 把整轨音频加入曲库。使用外置 CUE 时，将对应的 `.cue` 放在同一文件夹。使用内嵌 CUE 时，加入含有 CUE 的 FLAC 文件即可。
4. 打开椒盐的「专辑」，在专辑详情页点播「分轨」列表中的曲目。也可以在「歌曲」页搜索曲名并直接播放。

### 移除、隐藏和恢复 CUE 分轨

在「歌曲」页勾选一首或多首 CUE 分轨，再右键其中一首打开插件菜单。括号里的数字是本次操作的 CUE 分轨数。未勾选分轨时，菜单对右键点中的分轨操作，显示「（1）」。

- **从曲库移除所选分轨（N）**。分轨从歌曲列表、歌曲搜索结果和专辑详情页中移除。
- **从歌曲页隐藏所选分轨（N）**。分轨从歌曲列表和歌曲搜索结果中隐藏，仍可在专辑详情页浏览和点播。

**混选 CUE 分轨和普通歌曲时，无法用一个右键菜单移除全部条目，需要分两次操作。**

1. 先勾选要移除的 CUE 分轨，右键其中一首分轨，选择「从曲库移除所选分轨（N）」。如果只想从歌曲页隐藏这些分轨，则选择「从歌曲页隐藏所选分轨（N）」。
2. 再只勾选要移除的普通歌曲，右键其中一首，使用椒盐原生菜单的「从音乐库中移除」。普通歌曲包括单曲文件和整轨音频条目。

插件会在重启后保留分轨的移除和隐藏记录。两项操作均保留磁盘上的整轨音频和 CUE 文件。按 **Ctrl+Alt+U** 打开分轨窗口，点击「恢复隐藏和移除的分轨」，即可一次恢复全部由插件隐藏或移除的分轨。

## CUE 和封面怎么放

把 `Album.flac`、`Album.cue` 和可选的 `cover.png` 放在同一目录。CUE 的 `FILE` 行应指向实际音频，例如 `FILE "Album.flac" WAVE`。插件优先采用能匹配音频的同名 CUE，其次查找同目录中唯一匹配的 CUE。支持 UTF-8、GBK 和带 BOM 的 UTF-16。

找不到匹配的外置 CUE 时，插件读取 FLAC 的内嵌 CUE。优先使用带曲名和艺术家信息的文本标签。二进制 CUESHEET 块提供轨号和时间，曲名按 `TRACK 01` 等格式显示。

椒盐缺少原生封面时，插件按以下顺序查找。图片无法解码时继续尝试下一项。

| 优先级 | 文件名 |
| --- | --- |
| 1 | `cover.png` |
| 2 | `cover.jpg` |
| 3 | `folder.png` |
| 4 | `folder.jpg` |

## 设置

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 在歌曲页显示 CUE 分轨 | 开启 | 在「歌曲」页显示和搜索分轨 |
| 识别 CUE 后隐藏整轨 | 关闭 | 保留分轨，隐藏与 CUE 匹配的原整轨条目 |

## 兼容性与排查

- 专辑详情的分轨按椒盐曲库的专辑归类判断。该专辑的原始列表只有一条整轨记录时才显示分轨。即使音频分放在不同目录，椒盐归入同一专辑的记录也会一起计数。
- 按 **Ctrl+Alt+U** 可查找当前 CUE 或手动打开外置 CUE。独立分轨窗口可查看引用多个文件的 CUE，双击当前播放文件内的分轨可跳到起点。
- 如果专辑页没有分轨，先检查专辑里的整轨条目数。使用外置 CUE 时再检查 `FILE` 行和文件位置。可用独立分轨窗口的「诊断」或「原生接口报告」继续排查。
- 原生界面通过 Workshop 接口接入。升级椒盐后，相关入口可能需要重新适配。
