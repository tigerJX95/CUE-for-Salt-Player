# 开发与发布检查

每次修复从最新正式源码或已确认的联动源码继续，保留 CUE 播放与数字化碟片的分轨标识约定。不能以早期测试包覆盖后续已经确认的代码。

## 自动检查

- `bash gradlew test`：检查 CUE 解析、FLAC 内嵌 CUE、时长、混合列表、跨碟布局、移除和隐藏、勾选与当前结果恢复范围、随机及队列衔接、封面和出碟联动标识。问题反馈模板的平台与提交前确认字段必须保持复选框。
- `bash gradlew plugin`：先运行完整单元测试，再生成测试插件；单元测试失败时不打包。
- 开发期间在 `gradle.properties` 设置 `previewVersion`，构建默认使用该测试版本。命令行的 `-PpreviewVersion=<版本>-test<N>` 可临时指定测试版本。发布正式版时清除该属性，并同步更新中英文 README。
- 运行 `bash gradlew test --tests 'spw.cue.IssueTemplateContractTest'` 可核对中英文 README 的当前版本、兼容验证表、安装包路径和问题反馈模板中的版本示例，并检查最新版是否重复写入历史更新。
- `bash gradlew releasePlugin -PspwHostArchive=/path/to/SaltPlayer-ffmpeg-x64.dll`：正式打包入口。除单元测试外，必须通过真实宿主检查；缺少宿主归档或检查失败时，不生成本次正式插件。
- Windows 可使用 `release.cmd "C:\path\to\SaltPlayer-ffmpeg-x64.dll"`。宿主归档也可通过 `SPW_HOST_ARCHIVE` 环境变量指定。

真实宿主检查通过运行中的版本对应归档定位入口，验证主歌曲页、艺术家详情歌曲列表、专辑详情和封面接入，并以真实 Track 与分组数据模型执行分轨投影。检查混合普通歌曲、保留及隐藏整轨、隐藏／移除分轨、分轨时长、输入不变、页面隔离和 CUE 缺失后的回退。还必须通过真实右键菜单执行批量隐藏和批量移除，验证同一整轨的两首分轨都进入已打开及重新打开的恢复列表。临时音频与 CUE 样本在检查结束后删除，宿主归档不打进源码包。

GitHub 的 `CUE 回归检查` 工作流在 push 和 pull request 时执行单元与模板检查。公开 CI 不保存或分发椒盐宿主归档，因此真实宿主检查由正式打包入口强制执行。仓库如需阻止不通过的 PR 合并，应在分支保护中将 `regression` 设为必需检查。

## 界面回归

自动检查不能代替真实绘制和交互。正式发布前分别检查 Windows 微软商店、Windows Steam、Linux Steam。

| 页面或场景 | 必查内容 |
| --- | --- |
| 主歌曲页 | CUE 展开与搜索、普通歌曲混排、整轨显示开关、单选及全选。按标题排序，让普通歌曲夹在同一整轨的两个分轨之间，分别从普通歌曲和分轨点播，检查自动切换、上一首、下一首和列表循环按点播时的列表顺序执行。点播整轨时，确认时间轴显示整个文件的时长，跨过第一首分轨终点仍持续播放。再点播同一文件的任意分轨，时间轴应切换到分轨时长 |
| 艺术家详情的歌曲列表 | 无需先打开主歌曲页即可展开分轨；搜索分轨曲名和普通歌曲，清空后恢复列表；封面、时长、点播、选择和移除可用 |
| 单碟与双碟专辑详情 | 每碟整轨紧跟各自分轨；隐藏整轨后的布局、顶部歌曲统计、强调色正常 |
| 多碟共用 CUE | 在专辑父目录的 CUE 中用 `FILE` 引用各分碟目录的整轨。增删其中一碟的 `FILE` 后，从另一碟触发重新识别，检查歌曲页同步增删对应分轨 |
| 重新识别与管理窗口 | 保持同一专辑的管理窗口打开并勾选分轨，修改 CUE 后在专辑页重新识别。窗口应同步更新，保留搜索、筛选和仍存在的勾选。播放期间重新识别时，播控条应直接更新分轨信息，删除 CUE 后应恢复整轨显示 |
| 封面 | 外置 CUE 的目录图片、双碟共享图片、FLAC 内嵌封面均正常 |
| 播放与联动 | 顺序播放和列表循环中，从专辑页点播 CD1，末分轨自然播完后进入 CD2 的第一首可播放分轨。覆盖 CD2 缺席、紧邻 CD1、与 CD1 中间有其他歌曲的队列，以及 CD2 首轨起点非零；检查 CD2 播完后按宿主模式继续队列、随机和单曲循环、分轨窗口跨碟点播、出碟联动 |
| 恢复与停用 | 连续隐藏三首和连续移除三首后，记录必须全部保留；勾选两条隐藏／移除分轨后计数和恢复范围一致；未勾选显示 0 且禁用勾选恢复；当前结果恢复不影响其他 CUE；修改 CUE 后重新识别、停用及重新启用正常 |

仅当自动检查和对应界面回归均满足时，才更新正式文件。
