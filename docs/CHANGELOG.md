# 更新日志

[中文](CHANGELOG.md) | [English](CHANGELOG_EN.md)

## v0.2.0 — 2026-11-13

- **FLAC 内嵌 CUE**。支持 `CUESHEET` 文本标签和二进制 CUESHEET 元数据块。有匹配的外置 CUE 时优先使用外置文件。WAV 整轨仍使用同目录的外置 CUE。
- **批量隐藏与移除分轨**。歌曲页可从右键菜单操作一首或多首 CUE 分轨，菜单显示本次操作的分轨数。隐藏只影响歌曲列表和搜索结果，移除还会从专辑详情页移除分轨。按 **Ctrl+Alt+U** 可恢复插件隐藏或移除的分轨。
- **列表显示**。调整专辑详情页整轨与分轨的时长样式，统一分轨时长的数字宽度，并补齐歌曲页 WAV 整轨的同目录封面。

## v0.1.0 — 2026-11-12

- **外置 CUE 分轨**。识别整轨同目录下匹配的 CUE，在椒盐专辑详情页显示轨号、曲名和分轨时长。点击曲目按 `INDEX 01` 定位播放，可在设置中隐藏原整轨条目。
- **歌曲页分轨**。默认显示可搜索、点播、勾选和全选的分轨条目。可右键隐藏单首分轨，并在独立分轨窗口中恢复。隐藏仅影响歌曲页，专辑页继续完整显示。
- **分轨播控**。播控条和播放界面显示当前分轨的信息及进度，上一首和下一首可切换到相邻分轨。
- **艺术家与桌面标题**。优先读取 CUE 中的有效艺术家，缺少时使用整轨或专辑艺术家。Windows 任务栏和 Ubuntu Dock 窗口预览会随分轨更新曲名和艺术家。
- **同目录封面**。当原生封面缺失时，为专辑卡片、专辑详情、歌曲列表、播控条和播放界面补充封面。
- **独立分轨窗口**。按 **Ctrl+Alt+U** 查找当前 CUE、手动打开 CUE、恢复歌曲页隐藏的分轨或查看原生接口报告。

目前只适配了外置 CUE 播放。内置 CUE 将在后续版本中支持。
